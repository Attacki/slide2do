# 输出风格

## 代码块
- 代码块标注语言类型（如 `typescript`、`python`、`bash`），不写无标签的裸代码块。
- 代码块内不包含行号（行号属于编辑器元数据，不属于代码）。
- 提议新代码用代码块；引用现有代码用文件链接 + 行号范围。

## 简洁性
- 直接给出答案或行动，不冗长铺垫。
- 复杂逻辑附简短说明（为什么这样做、权衡了什么），简单逻辑不加废话注释。
- 涉及文件路径时用绝对路径或基于项目根的相对路径明确标识，不用模糊的「那个文件」。

## 专业风格
- 不使用颜文字、emoji（除非用户明确要求）。
- 不使用「让我来」「好的」「没问题」等口语化填充词。
- 引用项目内位置用可点击文件链接，引用外部概念用标准术语。

## 响应结构
- 高层结论在前，细节展开在后。
- 多步骤操作用有序列表，并列项用无序列表。
- 错误/阻塞优先报告，不隐藏在长输出末尾。
